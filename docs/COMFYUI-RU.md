# ComfyUI → Blender (экспериментальная интеграция)

Статус: реализован мост API и автономные контрактные тесты. Генерация на GPU,
качество формы и полный импорт результата реального задания ещё не проверены.
Не считать эту интеграцию подтверждённым способом получить точную копию референса.

Требуются отдельно установленный ComfyUI, работающий локальный HTTP-сервер
(по умолчанию `http://127.0.0.1:8188`), Blender с активным MCP-дополнением
и checkpoint Hunyuan3D 2.0 single-view. Плагин не запускает сервер,
не скачивает веса и не устанавливает расширения автоматически.
Адрес меняется через `COMFYUI_URL`; разрешён только loopback HTTP.

Модель из [официального примера](https://docs.comfy.org/tutorials/3d/hunyuan3D-2):
`tencent/Hunyuan3D-2`, файл `hunyuan3d-dit-v2-0/model.fp16.safetensors`.
В ComfyUI он размещается как `models/checkpoints/hunyuan3d-dit-v2.safetensors`.
Размер около 4.93 GB, SHA-256:
`360bc281fc956d4acac0c3d36d5ec0ebf8cdddbf4b8892e894d12419388d479b`.
Веса не входят в MIT-лицензию плагина: у модели собственная лицензия Tencent.

## Работа через чат

1. `comfy_status`: проверить доступность сервера, узлы и checkpoint.
2. Подготовить PNG/JPEG с изолированным объектом на простом фоне.
   Автоматическое удаление фона пока не реализовано. Крылья и конечности
   должны быть видимыми; скрытые поверхности генератор достраивает предположительно.
3. `comfy_generate(image_path=..., seed=0, steps=20, resolution=192)`.
   Это генерация геометрии по фото, без текстур, скелета или анимации.
   Профиль рассчитан на первый тест с ограниченной памятью; 8 GB не гарантируют успех.
4. Сохранить возвращённый `prompt_id`; опрашивать `comfy_job` отдельными вызовами.
   При timeout отправки не отправлять задание повторно автоматически: оно могло попасть в очередь.
   `unknown` означает отсутствие сведений, а не ошибку или завершение.
5. Перед импортом прочитать `get_scene_info`. Вызвать `comfy_import(prompt_id=...)`.
   GLB сохраняется в `PLUGIN_DATA/.state/comfy/models`. Существующие объекты не удаляются,
   активный .blend не заменяется и не сохраняется. Повторный импорт тех же байтов пропускается,
   если в Blender остались объекты с соответствующей меткой.
6. Проверить результат через `look` и пространственную диагностику. Сохранить нужный
   .blend отдельно. Для анимации обычно требуется исправление формы, ретопология и риг.

Пока поддержан один встроенный граф Hunyuan3D 2.0. Произвольные workflow,
промпт → изображение, несколько ракурсов, текстуры и фоновые очереди — отдельные будущие задачи.
Нельзя подставлять turbo/2.1 checkpoint в этот профиль и считать его проверенным.

## Проверка разработчиком

`python -m unittest discover -s tests -p test_comfy.py -v`

Это тесты с подменённым HTTP API: состояния очереди, отсутствие модели,
ошибки HTTP, некорректный GLB и передача импортирующего кода.
Они не запускают ComfyUI/Blender и не доказывают качество генерации или работоспособность CUDA.
