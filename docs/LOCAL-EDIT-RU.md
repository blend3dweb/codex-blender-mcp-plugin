# Локальные правки — версия 1.3

Инструменты: `edit_capabilities`, `edit_session`. Они дополняют пространственную диагностику и `look`.

1. Сохраните рабочую сцену отдельным .blend перед значительными изменениями. Проверьте объект через `spatial_inspect`. Выберите камеру и получите `look(mode="camera", shading="solid")`.
2. Создайте снимок: `edit_session(operation="snapshot", objects=["Head"], options={"label":"Челюсть"})`. Сохраните возвращённый `snapshot_id`.
3. Примените локальную правку: `edit_session(operation="deform", options={"snapshot_id":"…", "center":[0,0,1], "radius":0.5, "displacement":[0,0,0.05]})`. Центр, радиус и смещение заданы в мировых единицах Blender. Воздействие плавно уменьшается до нуля на границе радиуса. Смещение не должно превышать радиус.
4. Выполните `edit_session(operation="compare", options={"snapshot_id":"…"})` и повторите `look` из той же камеры. Численная разница показывает объём изменения, а не его художественное качество. `same_camera_and_frame` не сравнивает свет, материалы и все настройки viewport.
5. Если правка неудачна, вызовите `restore` с тем же идентификатором. Для сохранения результата достаточно оставить геометрию и сохранить .blend; `discard` освобождает снимок, не изменяя сетку.

Ограничения: Object Mode, локальные single-user mesh-объекты без shape keys. Изменяется базовая сетка, не результат модификаторов. Одновременно до 4 снимков, суммарно до 128 МБ исходных координат. Временные вычислительные буферы требуют дополнительной памяти.

Откат восстанавливает только координаты. Если после снимка изменились координаты вне этого инструмента, топология, объект сетки или трансформация, операция откажется перезаписывать новую работу. Все объекты проверяются до изменения любого из них. Нет принудительного обхода конфликта. Снимки непостоянные: перезагрузка файла/Blender их удаляет.

Для нескольких объектов центр и радиус общие. Укажите только действительно нужные объекты: связность, коллизии, анатомия и толщина после деформации автоматически не гарантируются.
