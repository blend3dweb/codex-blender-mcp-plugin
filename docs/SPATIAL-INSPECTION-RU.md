# Пространственный осмотр — версия 1.2

Модуль добавляет измеримую обратную связь из Blender. Он не восстанавливает трёхмерную форму автоматически по фотографии и не гарантирует художественного сходства.

## Подключение

Обновите папку пакета версией 1.2, выполните `python scripts/setup.py` согласно основной инструкции и перезапустите MCP-клиент. Если уже зарегистрирован путь к этой папке, повторная регистрация не нужна. Для новой установки используется `python scripts/setup.py --register-codex`. Дополнение Blender и протокол не изменились: нужен запущенный сервер дополнения на порту, указанном в конфигурации. Рабочее подключение пользователя автоматически не изменяется при сборке пакета.

После соединения должны появиться `spatial_capabilities` и `spatial_inspect`. Сначала вызовите `get_scene_info`, затем каталог возможностей. В этой версии всего 13 MCP-инструментов; 13 навыков включают новый `blender-spatial-inspection`.

## Осмотр без финального рендера

Существующий `look` получает изображения viewport. Пример: `mode="angles"`, `target=["Dragon"]`, `views=["front","right","top","three_quarter"]`, `shading="solid"`. Также доступны `wireframe` и `xray`. Для произвольного направления используйте в `views` вектор от центра объекта к наблюдателю, например `[1,-1,0.5]`. `distance` задаёт приближение относительно центра цели. Названия видов относятся к мировым осям Blender: «front» не обязательно соответствует морде персонажа.

Нужен интерактивный viewport Blender: фоновый CLI не равнозначен этому режиму. Читайте текст ответа `look`: если произошёл переход к обычному viewport, запрошенный набор ракурсов не был получен. Изображения должны реально возвращаться в ответе MCP.

## Численная диагностика

Все новые операции выполняются через `spatial_inspect(operation=..., objects=[...], options={...})`, не изменяют геометрию и требуют Object Mode. Параметры, ограничения и значения по умолчанию доступны в `spatial_capabilities`.

| Операция | Результат |
| --- | --- |
| `topology` | Связные компоненты, свободные вершины/рёбра, граничные и неманифолдные рёбра, вырожденные грани. |
| `elements` | Вершины, рёбра или грани с индексами, координатами и нормалями в мировом пространстве. Порции до 500 элементов. |
| `section` | Отрезки пересечения сетки с плоскостью. Выдаются признаки усечения и число пропущенных копланарных треугольников. |
| `proximity` | Выборочные расстояния от вершин первого объекта до поверхности второго. |
| `project` | Проекции указанных вершин через заданную камеру и отклонения от вручную заданных точек изображения. |

### Найти висящие зубы

1. Осмотрите челюсть с нескольких сторон через `look`.
2. Если зубы и голова — один объект, вызовите `topology`: один объект может состоять из отдельных островков. Если они отдельные объекты, запросите `proximity` с зубом первым и челюстью второй.
3. Посмотрите основания зубов через Wireframe/X-Ray. Малое расстояние не означает связности; положительное выборочное расстояние не исключает пересечение между гранями. Операция не определяет глубину проникновения или наличие коллизии.
4. После локальной правки повторите те же ракурсы и запросы. Не заменяйте проверку автоматическим объединением всей сцены.

### Сопоставить модель с фотографией

Зафиксируйте камеру и соотношение сторон изображения. Через `elements(evaluated=false)` выберите вершины-ориентиры. Передайте в `project` имя камеры и `landmarks=[{"vertex": 42, "uv": [0.2, 0.4]}]`. UV нормализованы от 0 до 1; начало в верхнем левом углу. Результат содержит ошибку в пикселях при текущем разрешении сцены, глубину и видимость точки. Точки позади камеры исключены из RMS. Малое отклонение доказывает только совпадение выбранных проекций, а не правильную анатомию или глубину.

## Координаты и индексы

Все координаты мировые; расстояния в единицах Blender. `meters_per_unit` сообщает масштаб единиц. По умолчанию рассматривается результат модификаторов; для `project` по умолчанию используется базовая сетка. Индексы результата модификаторов нельзя без проверки применять к исходным вершинам. Передавайте полученный `geometry_hash` как `expected_hash` при повторном использовании индексов: устаревший снимок будет отклонён. Хеш не блокирует будущие изменения сцены и не является транзакцией.

Ограничение одного запроса — 2 млн вершин или граней. Анализ самопересечений, автоматический подбор камеры, распознавание ориентиров на фотографии и автоматическая оценка сходства пока не реализованы.
