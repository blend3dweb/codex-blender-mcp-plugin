# Участие в разработке

Принимаются issues с воспроизводимыми ошибками и pull requests. Идеи ближайших этапов перечислены в [ROADMAP.md](ROADMAP.md).

## С чего начать

1. Сделайте fork и создайте отдельную ветку.
2. Выполните `python scripts/setup.py` без регистрации в основной профиль Codex.
3. Запустите проверки из раздела «Разработка и тесты» в README. Для снимков viewport нужен интерактивный Blender; фонового процесса недостаточно.
4. Добавьте проверку наблюдаемого поведения для исправления. Опишите проблему, результат, версию Blender и выполненные тесты в PR.

Хорошие первые задачи: автоматическая пара изображений до/после с фиксированными настройками; дополнительные сценарии проверки геометрии; документация Linux/macOS. Для большой архитектурной работы сначала опишите предложение в issue, чтобы согласовать область изменений.

## Границы изменений

- Не изменяйте vendored upstream без отдельного обоснования и обновления UPSTREAM.json. Сохраняйте авторство и лицензии.
- Не отключайте защиту отката от посторонних изменений и не выдавайте выборочное расстояние за надёжную проверку пересечений.
- Не включайте ключи, токены, `.env`, пользовательские настройки, личные сцены и логи с приватными данными. Предпочитайте минимальные синтетические сцены для воспроизведения ошибки.
- Для сторонних моделей и изображений нужны права на распространение. Не прикладывайте скачанные ассеты автоматически.
- Пакет распространяется под MIT. Вклад должен иметь совместимые условия использования.

При сообщении об ошибке укажите ОС, версию Python и Blender, точный инструмент/параметры, ожидаемое и фактическое поведение. Секреты и личные пути из логов удаляйте перед публикацией.
