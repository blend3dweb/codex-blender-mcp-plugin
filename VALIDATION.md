# Проверки

## Версия 1.4.1 — ComfyUI

1 ноября 2026 года: 9 автономных контрактных тестов `tests/test_comfy.py`.
В установленной копии зарегистрированы 19 MCP-инструментов. Через настоящий MCP
проверены живой ComfyUI 0.34.2, наличие узлов/checkpoint, отправка двух заданий,
состояния running/completed, импорт результата и повторный импорт без дубликатов.
Blender 5.2.2 LTS запущен отдельно на другом порту: основная рабочая сцена не заменялась.
RTX 5050 Laptop 8 GB: оба задания завершились без OOM. Веса проверены по SHA-256.
GLB и .blend сохранены; три вида второй сетки просмотрены. Подробности и ограничения
художественного результата: [ComfyUI](docs/COMFYUI-RU.md).

## Версия 1.3

1 ноября 2026 года. Windows, Python 3.13, Blender 5.2.2 LTS. Проверки выполнены из отдельной рабочей папки этого репозитория.

| Набор | Проверки |
| --- | ---: |
| Студийные операции | 19 |
| Пространственная диагностика | 21 |
| Снимки, локальные правки, сравнение и откат | 19 |
| Настоящий MCP через отдельный Blender | 10 |
| **Всего** | **69** |

Отчёты: [studio](docs/validation/studio-results.json), [spatial](docs/validation/spatial-results.json), [edit](docs/validation/edit-results.json), [MCP](docs/validation/mcp-results.json).

MCP подтвердил 15 инструментов, снимок координат, локальную правку, сравнение с неизменной камерой/кадром, изображения до/после, точный откат, отказ при постороннем изменении и освобождение снимка. Изображения до/после просмотрены. Проверки геометрии включают масштаб объектов, связность, сечения, выборочные расстояния, базовые/evaluated индексы и неверные параметры.

Установщик создал отдельную .venv; `pip check` прошёл. Манифесты проверены JSON Schema. Источники upstream сохранены без изменений. Настройки основного профиля Codex и дополнения пользователя не изменялись.

Ограничения: снимки хранят координаты в памяти текущего Blender, не заменяют .blend и не восстанавливают всю сцену. `same_camera_and_frame` не проверяет свет и все параметры viewport. Численные проверки не доказывают художественного сходства, правильной анатомии, отсутствия самопересечений или готовности к анимации. Автоматический визуальный цикл и запись демонстраций перечислены отдельно в ROADMAP.md.
