# План развития

## Приоритетный план: от изображения до анимации

[Подробный план пространственного скульптинга и связки Codex → ComfyUI → Blender](docs/SPATIAL-SCULPTING-PLAN-RU.md).

Первый этап — пространственное наблюдение, маска защищённой поверхности и
проверенная операция исправления выступа на тестовой форме. Затем — проба на
участке дракона. Перечисленные в плане будущие возможности не считаются реализованными.

## 1.3 — локальная правка и проверяемый откат

- [x] Пространственный осмотр и диагностика: возможности 1.2 сохранены.
- [x] Снимки координат явно заданных базовых сеток в памяти текущей сессии.
- [x] Локальное смещение в мировых координатах с плавным спадом воздействия.
- [x] Численное сравнение до/после, проверка неизменности камеры и кадра.
- [x] Восстановление исходных координат с отказом при постороннем изменении сетки.
- [x] Переносимые проверки в Blender и проверка через настоящий MCP.
- [ ] Автоматическая визуальная пара до/после из зафиксированных видов, включая стабильный масштаб и свет. Сейчас применяется `look(mode="camera")` до/после вручную в рабочем процессе.

Снимки 1.3 не заменяют сохранённый .blend и не откатывают материалы, модификаторы, топологию или всю сцену. Они исчезают при загрузке файла/выходе. Критерий готовности геометрического цикла: локальность воздействия, правильные мировые единицы при масштабе объекта, точный откат координат, защита посторонних правок и проверка в MCP.

## Последующий этап — демонстрации художника

- Запись состояния до, действий с параметрами, состояния после и объяснения результата.
- Экспорт демонстрации с явным выбором файлов и условий использования; никакой автоматической отправки сцен.
- Поиск подходящих примеров по задаче и области модели.
- Проверка приёмов на новых сценах, отсутствующих в примерах.

Это библиотека опыта и рабочие инструкции, а не переобучение параметров основной модели.

## Дальнейшие этапы

- Кистевые операции с масками и ограничением по поверхности; сохранение толщины.
- Надёжная диагностика пересечений и толщины, отдельная от выборочного proximity.
- Работа с референсом: ручные ориентиры, настройка камеры, стабильное наложение силуэтов.
- Управляемая ретопология и отдельные критерии качества органических моделей.
- Эксперименты с отдельной обучаемой моделью только при наличии датасета с правами, бюджета и измеримой проверки на отложенных примерах.

Число вершин, связность, совпадение ориентиров и отсутствие ошибок исполнения не считаются доказательством художественного сходства.
