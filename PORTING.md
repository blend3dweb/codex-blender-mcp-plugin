# Что переносится из плагина Kimi

Источник: [artmediastudio/kimi-blender-mcp-plugin](https://github.com/artmediastudio/kimi-blender-mcp-plugin), commit `251a7ee2d0c8af0837661539ff0f490b8dad7c69`. Проверены `kimi.plugin.json`, `skills/blender-mcp/SKILL.md`, README и лицензия.

В исходном комплекте **один навык**, а не библиотека отдельных навыков моделирования. Он задаёт рабочий процесс агента. Возможности управления Blender реализует внешний открытый сервер `ahujasid/blender-mcp` и дополнение Blender.

## Три части исходного комплекта

| Часть | Что делает |
| --- | --- |
| kimi.plugin.json | Описывает плагин, подключает папку навыка и запускает MCP по stdio командой `uvx blender-mcp`. |
| skills/blender-mcp/SKILL.md | Объясняет агенту настройку, проверку соединения, порядок работы, правила изменения сцены и диагностику. |
| assets/addon.py | Принимает команды в запущенном Blender через локальный сокет, выполняет операции и возвращает результат. |

Схема: Kimi → MCP-сервер → локальный сокет (обычно порт 9876) → дополнение → Blender/Python API.

## Поведение, заданное навыком Kimi

1. Включаться для создания, чтения и изменения сцен, моделирования, материалов, света, камер, рендера, снимков viewport, bpy и импорта ресурсов.
2. Помочь установить Blender, uv, зарегистрировать MCP и включить дополнение. Для Windows предусмотрен обход проблемы PATH через `cmd /c uvx` либо абсолютный путь.
3. Начинать с `get_scene_info`. Если связь не работает, разбирать подключение; не выдумывать содержимое сцены.
4. Осматривать сцену и объекты перед правками (`get_scene_info` / `get_object_info`). После структурных изменений получать снимок viewport, если важен внешний вид.
5. Предпочитать специализированные инструменты для запросов и импорта. Создание, преобразования, модификаторы, материалы, свет, камеры и рендер выполнять через `execute_blender_code`.
6. Писать код так, чтобы повторный запуск не создавал дубликаты: переиспользовать объекты по именам или заменять целевые объекты.
7. Строить сцену небольшими проверяемыми шагами.
8. Предупреждать о сохранении .blend перед разрушительными/экспериментальными операциями; в оригинале отдельно сказано подтверждать удаление объектов.
9. Не подключать второй MCP-клиент к той же Blender-инстанции.
10. Уметь объяснить три класса проблем: отказ/тайм-аут соединения, отсутствие uvx и конфликт подключённых клиентов.

## Внешние ресурсы в исходном навыке

| Сервис | Заявленное назначение |
| --- | --- |
| Poly Haven | HDRI, текстуры, модели; в исходном навыке — без ключа. |
| Sketchfab | Поиск и скачивание моделей; для ограниченного контента может понадобиться аккаунт/токен. |
| Hyper3D Rodin | Генерация 3D по тексту или изображению; в исходном навыке указан API-ключ. |

Оригинал предписывает при ошибке авторизации остановить повторы и запросить ключ. В нашей адаптации сохранена остановка повторов, а ключ пользователь настраивает в параметрах сервиса, без передачи в чат.

## Соответствие инструментов в нашей версии

Kimi запускает пакет без фиксации версии, поэтому его реальный набор инструментов может меняться. Нельзя гарантировать точное соответствие одними именами из SKILL.md.

| Исходное назначение | Наш сервер с зафиксированной версией |
| --- | --- |
| get_scene_info | get_scene_info |
| get_object_info | Фильтр get_scene_info; подробные свойства — чтение через bpy в execute_blender_code. Отдельного get_object_info в tools/list нет. |
| execute_blender_code | execute_blender_code |
| Снимок viewport | look |
| Просмотр готового рендера | look(image="Render Result") |
| Поиск/импорт ресурсов | search_assets / import_asset |
| Генерация Rodin | generate_3d с выбранным провайдером; внешняя интеграция отдельно не тестировалась. |
| Регистрация в Kimi | scripts/setup.py --register-codex |
| Диагностика | scripts/check_connection.py + проверка панели Blender |

Правило сохранения проекта перенесено как резервное сохранение перед широкими разрушительными изменениями. Уже явно разрешённое пользователем удаление/замена не требует повторного вопроса. Если границы удаления неясны, их нужно уточнить.

Наши дополнительные возможности упаковки: конкретный commit сервера и согласованное дополнение, отдельная .venv, зафиксированные зависимости, отключённая телеметрия и резервная копия конфигурации при регистрации. Это дополнения к переносу, а не возможности исходного навыка Kimi.

## Что этот плагин не обещает

В исходном навыке нет готовых методик ретопологии, UV-развёртки, CAD/BIM, архитектурного проектирования или процедурного построения конкретных объектов. Агент пишет соответствующий bpy-код по запросу. Также это не отдельный универсальный файловый менеджер: доступ к .blend и ресурсам происходит через Blender и выполняемый Python.

Фактические проверки нашей реализации и ограничения перечислены в VALIDATION.md. Текущая рабочая конфигурация Codex ещё не подключена к комплекту.
