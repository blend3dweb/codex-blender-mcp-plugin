# Работа по участкам

Локальная папка `dragon/` содержит пользовательскую сцену и изображения и исключена
из Git целиком. Код процесса доступен в репозитории, пользовательские материалы — нет.

Структура проекта:

- `current.blend` — рабочая модель; обычный Ctrl+S сохраняет её.
- `checkpoints/` — отдельные неизменяемые копии перед правками и после проверки.
- `autosave/` — десять вращающихся аварийных копий и журнал последнего сохранения.
- `reference/` — исходный и подготовленный референсы.
- `inspection/` — виды всей модели, крупные планы и численные отчёты.
- `stages.json` — порядок участков и статус проверки.

`autosave.py` исполняется через MCP в нужном Blender после сохранения `current.blend`:

```python
EXAMPLE_ROOT = r'C:/path/to/plugin/example/dragon'
exec(compile(open(r'C:/path/to/plugin/example/autosave.py', encoding='utf-8').read(),
             'example/autosave.py', 'exec'))
```

Таймер проверяет изменённую сцену каждые 120 секунд. Он сохраняет копии только
при открытом `current.blend` этого проекта, в Object Mode и без блокировки интерфейса.
При переходе в другой файл не сохраняет его. Ошибки записываются в `autosave/status.json`.
Повторная установка заменяет предыдущий таймер; чужая непустая папка не перезаписывается.
После перезапуска Blender или загрузки файла таймер нужно подключить снова.
Код не включается автоматически из .blend. Аварийные копии не означают принятие формы.

Этапы: спина и основания крыльев → грудь и шея → лапы → голова и пасть →
перепонки → хвост → проверка всей модели. Для каждого участка: копия до,
фиксированные виды, топология/сечения по необходимости, локальная правка,
те же виды после и общий обзор. Не удалять выступы до проверки их связи с сеткой.
